Draco's point-cloud/mesh compression fuzz target (ASan build): parsing a malformed Edgebreaker-encoded connectivity stream triggers a global-buffer-overflow read of 4 bytes past a small, fixed lookup table that maps each of the five canonical Edgebreaker topology symbols (commonly labeled C/S/L/R/E) to its topology-bit-pattern value. Root cause: while replaying a per-context symbol sequence during connectivity traversal, the code pulls the next value out of a buffer of previously entropy-decoded symbols and uses that raw value directly as the index into the fixed 5-entry lookup table, without first checking that the value actually falls within the table's valid 0-4 range. That per-context symbol buffer is filled earlier from the bitstream using draco's generic raw/tagged entropy coder, whose symbol-alphabet width (and the count of symbols to read for that context) come straight from attacker-controlled stream fields rather than from anything tied to the small, closed set of topology symbols; a crafted stream can make that earlier entropy stage hand back a value with no relationship to the 0-4 range the lookup table expects. That out-of-range value later gets consumed, unvalidated, as the array index during traversal, landing one slot past the table's end and reading adjacent global memory.
