RDKit's V2000 molblock parser (MSan build): building a substance group's bond-attachment/coordinate record consults an atom index that was captured earlier by resolving a bookmark against the mol's atom table, but that bookmark's target atom object had already been swapped out and freed by an unrelated property line's atom-substitution logic earlier in the very same block, and because the swap never clears the stale entry from the bookmark table the group ends up holding a garbage atom index copied out of freed memory, so a later membership check that scans the group's recorded atoms to classify a bond as internal or external to the group reads that uninitialized index.
